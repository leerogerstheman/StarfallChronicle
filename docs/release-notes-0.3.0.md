## 玩法深化：道具闭环 / 追击 / 精英词缀

三个新系统，一条底线：引擎在 Node 里只有一份实现，客户端与测试读同一个事件流。

### 道具系统（v0.2.0 的孤儿代码变成真实可玩）

- 商店上架 **9 种消耗品**（治疗/高级药水、万能药、充能饮料、烟雾弹、爆裂弹、冰晶、炼金溶剂、**回生药剂**）
- 战斗指令栏新增「道具」按钮：背包面板、显示本场预算 `0/3`、Esc 关闭
- 每场战斗全队共享 **3 次**道具额度
- **战后掉落**直接进背包；Boss 保底掉落回生药剂；结算界面显示「拾获」
- 敌人也会喂药（声明式 `ai.itemKit`）：虫母一瓶治疗药水，深渊哨兵一瓶高级药水

### 追击系统

不占行动条、不耗战技点的限时免费行动：苍叶/御巫铃 **破防触发**、神代凛/白鸦 **终结技连协**、艾莉丝 **治疗触发**。全队每回合最多 3 次，嵌套深度上限 1。

### 精英词缀

精英 roll **1 个**、Boss roll **2 个**词缀（10 种）。词缀从战斗种子派生、可在客户端敌卡上看到；Boss 永不抽 `迅捷`/`凶暴` 这类纯强度雪球——只抽改变打法的东西。

### 修复（节选，完整清单见 CHANGELOG）

| 问题 | 症状 |
|---|---|
| `runEnemyTurn` 对道具决策取技能名 | 敌人吃药那一回合整个循环崩溃 |
| `executeDecision` 漏传 `isEnemy` | 敌方道具吃掉玩家预算 |
| 商店按条目存在判型 | 买药水变成买"装备"，永远用不了 |
| `primary` 选择器只接受存活目标 | 复活药指名倒下队友却复活了活人 |
| `downed` 选择器不收窄到指名目标 | 一枚复活药群体复活 |

### 验证

**161 项测试全绿**（引擎 68 / 集成 41 / 浏览器 23 / 美术 21 / 原生窗口 8），60 局平衡采样全满足（Boss 满配 57%，等级不足 13%）。

双击 `start.bat` 即玩。
